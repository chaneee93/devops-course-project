# M10 E2E 리허설 결과

## 시나리오
회원가입(Keycloak self-registration) → 로그인 → 강의목록 → 수강신청(정상/정원초과/시간중복)
→ 시간표 확인 → 수강취소

## 1차 리허설
| 단계 | 결과 |
|------|------|
| 회원가입 | ✅ Keycloak 가입 페이지 연동 정상 |
| 로그인 | ✅ 토큰 발급/저장 정상 |
| 강의목록 | ⚠️ 최초 안 뜸 → 아래 발견 #1 |
| 수강신청(정상) | ✅ |
| 수강신청(정원초과) | ✅ 정원마감 차단 |
| 수강신청(시간중복) | ✅ 시간중복 차단 |
| 시간표 | ✅ 요일·시간 정렬 표시 |
| 수강취소 | ✅ 목록/시간표에서 제거 |

### 발견 이슈
| # | 증상 | 원인 | 개선안 |
|---|------|------|--------|
| 1 | 강의목록 최초 미표시 | M9 장애주입(pod kill/cordon)으로 `kubectl port-forward`가 물려있던 pod가 사라지며 터널 끊김 | 로컬 접속을 pod에 종속된 port-forward 대신 **NodePort(32557)** 또는 Ingress 경유로 안내. 실제 배포(EKS+ALB)에선 미발생 |

## 2차 리허설 (개선 반영)
- 개선: 접속 경로를 `http://<minikube-ip>:32557`(NodePort, kube-proxy 로드밸런싱)로 변경 → pod 재생성에도 무중단
- 재확인: 위 전 단계 **재수행 → 전부 통과**, 강의목록 미표시 재현 안 됨
- 결론: 앱 로직 결함 아님(환경 접속 방식 이슈). 애플리케이션 시나리오는 처음~끝까지 정상 동작 확인
